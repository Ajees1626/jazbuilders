# Google la JAZ Builders site fast index ஆக (Fast indexing)

**Site:** https://jazbuildersgroup.com

## 1. Google Search Console add பண்ணுங்க

1. https://search.google.com/search-console open பண்ணுங்க  
2. **Add property** → **URL prefix** select பண்ணி `https://jazbuildersgroup.com` type பண்ணுங்க  
3. Verification: **HTML file upload** or **HTML tag** (meta tag) use பண்ணி verify பண்ணுங்க  

## 2. Sitemap submit பண்ணுங்க

1. Search Console la left side **Sitemaps** click பண்ணுங்க  
2. **Add a new sitemap** box la type பண்ணுங்க: `sitemap.xml`  
3. **Submit** click பண்ணுங்க  

இதனால Google எல்லா pages-ஐயும் fast discover பண்ணும்.

## 3. URL Inspection (single page fast index)

1. Search Console top la **URL Inspection** open பண்ணுங்க  
2. `https://jazbuildersgroup.com` type பண்ணி **Request indexing** click பண்ணுங்க  

Home page குறைந்த நேரத்துல index ஆகும்.

## 4. Live check பண்ண

- **robots.txt:** https://jazbuildersgroup.com/robots.txt  
- **sitemap:** https://jazbuildersgroup.com/sitemap.xml  
- **Home:** https://jazbuildersgroup.com/  

Site deploy பண்ணி இந்த URLs work ஆகுதானு check பண்ணுங்க. அப்புறம் Search Console la submit பண்ணுங்க.
